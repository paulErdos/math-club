Consider radial infinitesimal square from a point
---------------------------------------------------

Comment: it's weird we kind of take the derivative first before applying the function

1. Find corners

z0 = re^it
z1 = (r + dr)e^it
z2 = re^i(t + dt)

2. Take logs, find landing spots in w plane

log(z0) = log(re^it)        = log(r) + it
log(z1) = log((r + dr)e^it) = log(r + dr) + it
log(z2) = log(re^i(t + dt)) = log(r) + i(t + dt)

Amplitude 1/2 : horizontal / radial
------------------------------

1. |w1 - w0|

horizontal side's endpoints
* |w0| = |log(r) + it|
* |w1| = |log(r + dr) + it|

Meaning the length is
* | w1 - w0 | = | log(r + dr) + it + -log(r) -it | = log(r+dr) - log(r)
= log((r + dr) / r) = log(1 + dr/r) = What do I do with this?

-----vvv begin wandering in the desert vvv ---
(1 + x)^n = sum from k = 0 to n of (n choose k)x^k
n choose k = n! / (k!(n-k)!)
n choose 0 = n! / (0!(n-0)!) = 1
n choose 1 = n! / 1!(n-1)!   = n
n choose 2 = n! / 2(n - 2)!  = n(n-1)/2
n choose 3 = n| / 6(n-3!)    = n(n-1)(n-2)/6
n choose 4                   = n(n-1)(n-2)(n-3)/24
n choose k = (1/k!) product from i = 0 to k of (n - i)

For n = 1, all n choose k for k > 1 = 0.

          = sum from k = 0 to 1 of [(1/k!) product from i = 0 to k of (n - i)]x^k

Nope. Definition of the differential

d(log(r)) = log(r + dr) - log(r).
so 

| w1 - w0 | = | log(r + dr) + it + -log(r) -it | = log(r+dr) - log(r) = d(log(r)) = 1/r * dr = dr/r

2. |z1 - z0|

|z1 - z0| = r + dr - r = dr

3. Ratio

Amplitude = |w1 - w0| / |z1 - z0| = 1/r * dr * 1/dr = 1/r. 


Amplitude 2/2: vertical / tangential
-------------------------------------------------------------------

Amplitude = |w2 - w0| / |z2 - z0|

Vertical: w2 - w0
----------------------

w0 = log(z0) = log(re^it)        = log(r) + it
w2 = log(z2) = log(re^i(t + dt)) = log(r) + i(t + dt) = log(r) + it + idt = w0 + idt

w2 - w0 = logr + i(t + dt) - logr - it = it + idt - it = idt

w2 and w0 are separated by dt. 
So w2 = w0 + idt

so w2 - w0 = w0 + idt - w0 = idt. 

Then 
|w2 - w0| = |idt| = | 0 + idt | --> root(0^2 + dt^2) = dt

so
|w2 - w0| = dt. 


Orthogonal: z2 - z0
---------------------

z0 = re^it
z2 = re^i(t + dt)

z2 - z0 = re^it * e^idt - re^it = re^it(e^idt - 1)

|z2 - z0| = |re^it(e^idt - 1)| = |re^it||(e^idt - 1)| = r|(e^idt - 1)|

Wait.

These two points are separated by dt angle, and so the arc length s = rt = rdt
so

|z2 - z0| = rdt. 

I probably should have thought of this earlier. 


Ratio: |w2 - w0| / |z2 - z0|
-----------------------------

w2 - w0 / z2 - z0 = dt / rdt = 1/r 


So they're the same in both directions.

So magnitude is 1/r confirmed.

Twist
==========

Vector z1 + z0 has angle theta
Vector w1 + w0 has angle zero.

So the twist is

Twist = 0 - theta = -theta. 

So twist is e^(i*(-theta)) confirmed.
