Complex Function Mapping Guide

This application demonstrates how complex-valued functions f: ℂ → ℂ act as a continuous spatial warping or restructuring of the entire complex plane, rather than plotting single curves.

Key Built-in Transformations

  • exp(z): Exponential function (periodically maps horizontal strips into concentric circles and rays).
  • z^2: Squares coordinates and doubles angles, doubling winding numbers.
  • log(z): Principal branch of complex logarithm (inverts exponential map).
  • 1/z: Inversion mapping circles and lines into circles and lines while swapping inside/outside.
  • circle_inv: Inversion with respect to the unit circle (1 / conj(z)).
  • mobius: Möbius linear fractional transformation (2*z + 1) / (z + 2).
  • translation: Shifts plane by z + 2 + 1i.
  • rotation: Rotates plane by an angle z * exp(0.5i).
  • reflection: Complex conjugation conj(z).

Math Syntax Supported

Powered by Math.js, you can write expressions using standard notation such as z^3 - 1, sin(z), cos(z), or sqrt(z). Imaginary unit i is fully supported.
